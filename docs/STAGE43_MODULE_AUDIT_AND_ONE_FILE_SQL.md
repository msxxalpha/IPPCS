## دیتابیس یکپارچه

- **فایل نهایی برای SSMS:** `IPPCS_Dev_Complete_Install.sql` از آخرین اجرای موفق GitHub Actions، Artifact `IPPCS_Dev_Complete_Install_SQL`. همین ملف مطابق `scripts/Export-IPPCSDatabaseSql.ps1` در رایانه کاربر قابل بازتولید است.
- **منبع حقیقت واحد:** `src/IPPCS.Web/Migrations/CI/`، بدون دستی ساختن جدول موازی.
- **امکانات فایل:** `CREATE DATABASE [IPPCS_Dev]` فقط در صورت نبودن دیتابیس، قفل اجرا روی بانک دارای جدول‌های ناشناخته، `__EFMigrationsHistory` و تغییرات مرحله‌ای، Seed واحدهای فنی و کدهای پایه، ساخت Identity و ده‌ها جدول تولید؛ نه رمز حساب و نه اتصال خارجی.
- **اولین ورود:** حساب Administrator صرفاً در اجرای برنامه با User Secrets قوی ساخته می‌شود؛ نه در SQL.
- **محدودیت:** نصب SQL سبز یا اجرای ویژوال استودیو نمی‌تواند گواه استقرار واقعی باشد. برای شروع از `docs/FIRST_RUN_VISUAL_STUDIO.md` و `database/README.md` و بخش راهنمای داخل `/help.html` استفاده کنید.

## گام بعدی بعد از اولین اجرا
